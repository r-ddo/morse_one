# morse_one 計画書

iPhone で空き時間に使える、モールス符号（欧文）受信練習用の個人向けウェブアプリ。

- 作成日: 2026-09-30
- 最終目標: 第一級総合無線通信士（1総通）電気通信術の欧文暗語受信に合格できる受信力
- 当面の範囲: 欧文（英字・数字・一部記号）のランダム文字列。和文は将来対応

## 1. 背景と課題

- 符号自体は覚えているが、文字間隔がかなり空いていないと思い出すのが追いつかない
- 定型文（599 BK など）ではなく、ランダムな暗語を聞き取れる必要がある
- 最終的には 5 文字グループを連続して聞きながら書き取る「遅れ受信」が必要

## 2. 練習方針

| 方針 | 内容 |
|---|---|
| Farnsworth 方式 | 文字速度（符号そのもの）は最初から速く（20〜25 WPM）、文字間・語間だけ広げる。上達に応じて間隔を詰める |
| 即時認識 | 点・線を数えず、音のパターンを文字として丸ごと認識する。反応時間を計測し、遅い文字も苦手とみなす |
| 苦手集中 | 文字ごとの正答率・反応時間・取り違えを記録し、出題を苦手に寄せる |
| 段階的な遅れ受信 | 1 文字遅れ → 5 文字（1 グループ）遅れへ段階的に広げる |
| 短時間セッション | 1 回 3〜5 分。ワンタップで開始 |

### 速度の定義

- 短点長 `dot = 1.2 / cwpm` 秒（PARIS 基準）
- 文字速度 `cwpm` は固定し、実効速度 `ewpm` を Farnsworth（ARRL）式で伸ばした文字間・語間で実現する
  - 追加遅延 `ta = (60·cwpm − 37.2·ewpm) / (cwpm·ewpm)` 秒
  - 文字間 `tc = 3·ta / 19`、語間 `tw = 7·ta / 19`
- 字/分 ⇔ WPM: ランダムな暗語は PARIS より符号が長いため、5 字 ≒ 1 語では換算できない。
  5 字 1 組・標準間隔で 80 字/分 ≒ 英字のみ 19.2 WPM、英数字 21.8 WPM（100 字/分 ≒ 24.1 / 27.3 WPM）
- 字/分で速度を指定するモード（遅れ受信・模擬試験）は、文字速度を保ったまま文字間・語間（3:7）を伸縮して合わせる。
  文字速度が足りず届かない場合は注意を表示する

## 3. 練習モード

### A. 単字即答（最優先）
- 1 文字が鳴ったら即入力。反応時間を記録
- 目標時間（初期値 3 秒）を自動調整: 10 問ごとに目標時間内の正答率が 90% 以上なら 0.9 倍、60% 未満なら 1.15 倍（0.4〜6 秒）。固定値も選べる
- 目標時間を過ぎた正解は「遅い正解」として正解の符号を聞き直す。目標時間の 3 倍（3〜10 秒）で打ち切り
- 誤答時は正解の符号 → 自分の答えの符号の順に鳴らして聞き比べる（再生中の行を ▶ で強調表示）

### B. 5 文字グループ受信
- 5 文字を Farnsworth 間隔で再生 → 入力 → 文字ごとに正誤表示 → 次のグループ
- 実効速度（初期値 5 WPM）を自動調整: 3 グループ（15 文字）ごとに正答率 90% 以上なら約 1.1 倍（文字間を詰める）、80% 未満なら約 1/1.1 倍（2 WPM〜文字速度）。固定値も選べる
- 再生中から入力可能。聞き取れない文字は「不明」で飛ばし、5 文字入力または「確定」で採点（位置ごと）
- 全問正解なら自動で次へ。間違いがあれば「もう一度聞く」「次へ」を選ぶ
- 結果画面に間違えた文字と取り違え（正解→入力）を表示
- 文字セット選択: 英字のみ／英字＋数字／＋記号（`/ ? .` 等）

### C. 遅れ受信（連続ストリーム）
- グループ間で止めずに流し続ける。速度は字/分で指定（初期値 30 字/分）
- 許容する遅れ（1/2/3/5/10 字）を設定し、段階的に広げる。遅れ = 鳴り終わった字数 − 入力した字数
- 最終形は「今のグループを聞きながら、前のグループを入力する」
- 遅れが許容を超えると赤く警告し、最大の遅れと超えた回数を記録
- 採点は試験の基準（誤字・冗字 3 点、脱字 1 点）。減点が最小になるように入力と問題を対応付けるため、1 字抜かしても以降がずれない
- 結果画面で正解と入力を並べて表示し、400 字換算の得点も出す
- 速度の自動調整: 正答率 90% 以上かつ遅れが許容内なら約 1.1 倍、80% 未満なら約 1/1.1 倍（10〜150 字/分）

### D. 模擬試験（手書き）
- 「HR HR」の後に一様ランダムな 5 字 1 組の暗語を流し、最後に「AR」。速度 30〜100 字/分、長さ 1/3/5 分
- 紙に書き取り、終了後に正解を表示。誤字・脱字・冗字・抹消訂正の数を入力して自己採点（品位は除く）し、履歴に保存
- 本番は手書きのため、スマホ入力とは別に必ず練習する
- 再生中は画面が消えないようにする（Screen Wake Lock。非対応の環境では何もしない）
- 電報形式の前付け（番号・語数・日付など）は形式を確認できていないため未対応

## 4. 苦手を集中的に出す仕組み

- 記録
  - 文字ごと: 正答率・反応時間（直近重視の指数移動平均）、最終出題日時
  - 取り違え表: 「何を何と間違えたか」（H↔5、B↔6、V↔4、S↔H など）
- 出題配分: 苦手な文字から約 60%、全体からランダムに約 40%
- 苦手度: `誤答率·a + 遅さ·b + 久しぶり度·c` の重み付けから始め、使いながら調整
- 取り違えは向きを区別せずに集計し、半減期 14 日で古いものほど軽くする
- 自動の差し込み
  - 単字即答: 誤答した文字と取り違えた文字を、以降の問題に 1 問おきに計 4 問（時間切れなら誤答した文字を 2 問）混ぜる（「復習」表示）
  - グループ受信: 取り違えた 2 文字（なければ聞き逃した文字を最大 2 つ）を次のグループのランダムな位置に入れる
- 聞き分け練習（2 択）: 取り違えの多い組み合わせ、または記録がなければよくある組み合わせ（H/5、S/H、B/6、V/4 など）を選ぶ
  - 最初に 2 つの符号を順に聞かせ、その後 20 問。同じ文字は 3 連続まで
  - 出題中は符号の表示を隠し、ボタンには文字だけを出す（符号を数える癖を防ぐ）
  - 2 択は簡単すぎるため、文字ごとの成績（苦手度）には反映しない

## 5. 入力 UI

- 標準キーボードは英字と数字の切り替えが遅いため、専用の画面キーボードを用意（数字段と英字段を常時表示、大きめのキー）
- 標準キーボードを使う場合は自動修正・自動大文字化をオフ

## 6. 音

- Web Audio API で送信時刻を事前にまとめて予約する（setTimeout は使わない）
- 立ち上がり・立ち下がりを 4〜5 ms かけてなめらかにし、クリック音を防ぐ
- 周波数 500〜800 Hz、音量を調整可能。将来は雑音・混信（QRM）を追加
- iOS のマナーモード対策: `navigator.audioSession.type = "playback"`（Safari 16.4 以降）。AudioContext は最初のタップで起動
- iOS でアプリを切り替えると AudioContext が止められ、戻っても resume() が終わらない・running なのに無音、ということがある。
  対策として、アプリを離れたら練習を中断して AudioContext を閉じ、次に練習を始めるタップで作り直す。
  resume() が 300 ms 以内に終わらない場合も作り直す。着信などで再生中に止められたときも練習を中断する

## 7. 技術構成

| 項目 | 採用 |
|---|---|
| 形態 | PWA（Safari からホーム画面に追加） |
| ビルド | Vite + TypeScript（UI フレームワークなし、必要なら Preact） |
| ホスティング | GitHub Pages（静的ホスティング、HTTPS。push で自動公開） |
| 設定の保存 | localStorage |
| 履歴・統計の保存 | IndexedDB（端末内のみ。サーバーには送らない） |
| オフライン | Service Worker（vite-plugin-pwa。更新は「新しいバージョンがあります [更新]」で利用者が選ぶ） |

### データ保存の注意点
- Safari とホーム画面アプリは保存領域が別 → 常にホーム画面から使う
- ホーム画面のアイコン削除・機種変更でデータは消える → JSON の書き出し／読み込みを用意し、ファイルアプリや iCloud Drive に保存
- `navigator.storage.persist()` を呼び、データを消さないよう要求する
- 書き出し: 解答の記録・文字ごとの成績・模擬試験・設定を 1 つの JSON（morse_one-YYYYMMDD.json）にまとめる。
  iPhone では共有シート（「ファイルに保存」）、共有できない環境ではダウンロード
- 読み込み: 形式を検証し、確認のうえ今のデータと設定をすべて置き換えて再起動（1 トランザクションなので失敗時は元のまま）

### 統計画面
- 今日の字数・連続練習日数・累計字数
- 直近 14 日のグラフ（1 系列ずつ、タップでその日の値、表でも表示）:
  練習した字数、正答率、単字即答の反応時間、グループ受信の実効速度、遅れ受信の速度（練習した種目のみ）
- 文字ごとの成績（苦手度順）と最近の取り違え
- 複数端末の同期が必要になったら、サーバー側の仕組みを検討（当面不要）

### ネイティブ版への移行を検討する条件
- ロック画面やバックグラウンドで聞き流したくなった場合
- PWA では音のタイミング精度が足りない場合

## 11. 試験条件（2026-09-30 調査）

### 第一級総合無線通信士 電気通信術（モールス電信）
無線従事者規則（平成二年郵政省令第十八号）の原文:

> 一分間七十五字の速度の和文、一分間八十字の速度の欧文暗語及び一分間百字の速度の欧文普通語によるそれぞれ約五分間の手送り送信及び音響受信

（第二級総合も同じ。第三級総合は和文 70 字・暗語 80 字・普通語 100 字でそれぞれ約 3 分間）

### 字数・配点・合格点（電気通信術 採点基準表）
| 種目（受信） | 字数 | 満点 | 時間 |
|---|---|---|---|
| 和文 | 375 | 100 | 5 分 |
| 欧文暗語 | 400 | 100 | 5 分 |
| 欧文普通語 | 500 | 100 | 5 分 |

- 合格点: 3 種目の合計 210 点。ただし 1 種目でも 30 点に達しなければ不合格（送信も同じ）
- 字数はモールス符号 1 個を 1 字と数える。開始の「HRHR」は数えない。
  電報形式で 2 通以上のとき、通の間に置く約 5 秒の間隔は欧文暗語では 7 字に換算
- 欧文暗語は欧文電報形式

### 受信の採点（不良点減点。減点が 100 点を超えるときは 100 点）
| 区分 | 減点 |
|---|---|
| 誤字、冗字 | 1 字ごとに 3 点 |
| 脱字、書体不明りょう | 1 字ごとに 1 点 |
| 抹消、訂正 | 3 字までごとに 1 点 |
| 品位 | 15 点以内 |

- 誤字 3 点に対して脱字は 1 点。聞き取れない字は当て推量で書かずに空ける方が有利
- 「m と w」「n と u」など、単独の 1 字として誤読されうる書体は不明りょう扱い

### 暗語の中身
- 5 字 1 組の英字・数字のランダムな並び、という説明が多い
- 一方で、一総通の受験記に「欧文暗語・欧文普通語ともに、数字も来るかと思いきや全部アルファベットでした」とある。
  当面は「英字＋数字」で練習し、英字のみでも練習できるようにしておく
- 受験記によると、前付けは NR の付いた発信番号・種類・発信局・語数・受付日・受付時刻などで、「/」で区切られる
